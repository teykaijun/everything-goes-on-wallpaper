Both app packages are downloadable from the [v3.1.0 GitHub release](https://github.com/teykaijun/everything-goes-on-wallpaper/releases/tag/v3.1.0). Source, app metadata, builders and installation guides are retained together.

## Wallpaper Engine Workshop — pending

The desktop automation helper failed to initialize with `windows sandbox failed: helper_unknown_error: setup refresh had errors`. No Workshop item was submitted and no Workshop URL exists yet.

The built folders under `dist/wallpaper-engine/` are ready to import into the Wallpaper Engine editor. Publish each project separately:

1. Open its `index.html` as a web wallpaper in the editor (or edit the installed local project).
2. Preview both day and night, schedule, soundtrack and Lux controls where applicable.
3. Choose Workshop → Share wallpaper on Workshop.
4. Use [arena description](WORKSHOP-ARENA.txt) or [window description](WORKSHOP-WINDOW.txt). Review its preview image, content tags and visibility; choose Public.
5. Complete Steam's required Workshop agreement or account prompts personally if shown, then publish. Record each item URL in this document and the README.

Do not claim a Workshop listing is live until Steam returns its public item URL. The reference workflow is [Wallpaper Engine's web-wallpaper guide](https://docs.wallpaperengine.io/en/web/first/gettingstarted.html).

## Lively sharing

The public Lively ZIP on GitHub is the distribution entry point. Users import it directly in Lively; see [setup](LIVELY.md). An official self-service Lively gallery submission route was not verified, and no gallery listing has been submitted. Do not confuse third-party websites using the Lively name with the [official project](https://github.com/rocksdanister/lively).
